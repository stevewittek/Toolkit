# SQL Server DBA Toolkit

This is a small public index of database engineering work by **Steven Wittek, Netherwood Data Partners**. The repository does not currently contain a released toolkit or production-ready scripts.

## Start with the completed engineering work

- **[QueryVault](https://github.com/stevewittek/Databases)**: SQL Server Query Store archiving with retained performance baselines, partitioned storage, Grafana reporting, documented validation, and actual screenshots.
- **[QueryVault's original use case](https://github.com/stevewittek/Databases/blob/master/docs/USE_CASES.md)**: preserving baseline load-test evidence before a database refresh and comparing workloads across a longer engineering project.
- **[Netherwood Data Partners](https://netherwooddatapartners.com/)**: software, data engineering and SQL Server consulting.

## Engineering approach

I focus on diagnosis before intervention, safe T-SQL, repeatable releases, observability, and preserving the evidence needed to measure the results of database changes.

For inspectable source and tested examples, use the projects above. This index will not claim unpublished or unverified tools as finished products.
